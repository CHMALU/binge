# Icons

UI icons MUST come from `react-icons` (default family: `react-icons/io5`). Never use Unicode emojis or text-symbol glyphs (🎬 📺 ★ ☆ ✕ ▶ ℹ → ● ⌘ +) as icons in JSX. See CLAUDE.md → "Icons — NO text/Unicode emojis" for details.
